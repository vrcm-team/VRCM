# VRCM 1.1.5：新功能详解

**Languages / 语言 / 日本語:** [English](1.1.5.md) / [中文](1.1.5_ZH.md) / [日本語](1.1.5_JP.md)

VRCM 1.1.5 新增二维码工具、统计数据迁移，以及支持账号切换的分类设置页，同时改进会话恢复、资料编辑、群组交互和 Android 应用内更新。

## 扫描 VRChat 二维码与分享个人主页

Android 和 iOS 可通过扫一扫使用相机或相册图片识别支持的 VRChat 链接。一张图片包含多个二维码时，可以选择需要识别的二维码。Android 还提供桌面图标的扫一扫快捷入口。

扫描 VRChat 设备登录码后，可在批准当前账号登录前查看请求时间和可用的来源地区信息。设备码过期或账号变化后需要重新确认。请只批准你正在登录的设备发起的请求。

独立的“我的二维码”页面支持展示个人主页二维码、切换样式和分享卡片。Desktop 不提供相机扫描。

## 在不同安装之间迁移统计数据

设置 → 隐私与数据提供统计导入和导出。可以导出 SQLite 文件备份，也可以导入支持的 VRCM 或 VRCX 数据库。导入前会展示用户、动态和相遇记录数量，重复记录会合并。

VRCM 备份会校验当前账号。VRCX 游戏日志可能包含多个账号的数据，导入后归入当前登录账号；切换账号会中断操作。Android 同时改善了大快照读取和系统文档选择器选取文件后的导入可靠性。

## 分类设置与账号切换

设置页将账号安全、外观、通知、隐私与数据、应用信息分为独立页面；通知选项按平台能力显示。账号与安全页集中提供已保存账号的切换和退出登录。

后台会话失效后，VRCM 会尝试恢复认证并继续更新。恢复结果绑定当前账号，避免延迟返回的请求覆盖更新的会话。

## 更清晰的动态与更可靠的交互

好友动态显示名称变更和模型更换，并提供独立的模型筛选。展开房间卡片后可打开房主主页；群组房间支持邀请自己，世界详情会加载进入页面时的来源房间。

资料编辑适配 VRChat 新的资料接口并同步保存结果；群组代表状态在不同资料页之间保持一致，模型列表更准确地展示平台支持，同时修复 Windows 渐进背景模糊导致的卡死。

## Android 更新与分发说明

GitHub 渠道的 Android 版本会核对下载 APK 的包名和签名是否与已安装应用一致。身份不符时会停止更新，不再继续尝试其他镜像；下载内容无效或传输中断时仍可切换来源重试。

Android 和 iOS 构建号递增至 10。实际可下载的安装包以 Release 附件为准。GitHub Android 版本使用系统安装器更新，Google Play 和 App Store 版本继续走各自商店的更新流程；iOS IPA 用于侧载。
