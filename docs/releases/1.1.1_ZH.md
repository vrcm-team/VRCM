# VRCM 1.1.1 新功能详解

**Languages / 语言 / 言語:** [English](1.1.1.md) · [中文](1.1.1_ZH.md) · [日本語](1.1.1_JP.md)

本文汇总从 `1.0.7` 到 `1.1.1` 的主要用户可见变化。这个版本的重点不是继续堆叠“查看资料”的入口，而是让 VRCM 成为更偏社交、更适合随身使用的 VRChat 伴侣：看懂自己的社交圈，留下共同游玩的本地记录，在手机上及时获知动态，并更快地从一个链接走到下一次游戏或线下见面。

相较于以桌面端信息管理和日志查看为重心的 VRCX，VRCM 更关注移动场景中的社交数据统计、系统提醒、游戏互动和线下交流。这是两者产品侧重点的区别，不表示 API、数据文件或功能上的兼容与替代关系。

文中的移动端画面均采集自 OPPO Android 实机。好友关系网截图已做整体脱敏；通知截图不包含真实好友通知正文。

## 1. 看懂关系，也记住一起玩过的时间

### 好友关系网

在自己的资料页打开更多操作，选择“查看好友关系网”，VRCM 会根据共同好友关系构建可交互图谱。

- **社区视图**会将联系较紧密的好友归为不同社交圈，并使用色彩和轮廓帮助辨认结构。
- **以我为中心**视图突出你与好友的连接，并列出共同好友数较多的联系人。
- 可缩放、拖动、选择节点和查看共同好友；顶部刷新会重新获取关系数据，页面也会优先复用本地缓存。
- 图谱会缓存到本机；再次打开可以先看缓存，再按需刷新。

关系网描述的是 VRChat 共同好友所形成的连接结构，不等同于现实中的亲密程度。文档截图已对好友头像和显示名整体脱敏。

### 好友活动与共同游玩统计

好友资料页现在会汇总 VRCM 本地观察到的社交数据：

- 最后见面时间、见面次数和共同游玩时长；
- 最近一起玩过的好友；
- 上线、下线、切换世界、状态变化和简介变化；
- 进入同一房间和离开共同房间的时间线；
- 世界名称和房间访问类型，以及简介变更的差异内容。

这些数据按账户保存在本地数据库中，不会上传到 VRCM 自建服务器。统计只覆盖 VRCM 运行期间观察到的状态；Android 开启后台监测后，应用退到后台时仍可继续观察。它不是 VRChat 提供的全量历史，也不会补齐安装 VRCM 之前的记录。

## 2. 从“看到动态”直接走到互动

VRCM 把移动端最常见的游戏互动收进资料、世界和通知流程：

- 在好友资料中查看对方房间，并邀请自己加入；
- 发送默认、爱心、挥手、大笑、点赞、思考、惊讶或生气等不同 Boop；
- 在通知中心处理好友请求、邀请和回戳；
- 查看共同好友、共同群组、对方创建的世界与模型，再继续进入详情；
- 编辑自己的状态、状态描述、简介、人称代词、语言和社交链接；
- 通过系统分享面板分享用户、世界、群组和模型的 VRChat 官网链接。

这部分的目标是缩短“发现一个人或一个世界”到“下一步真的去互动”的距离，而不只是在手机上复刻资料浏览。

## 3. 复制一个链接，回到 VRCM 就能继续

聊天软件、浏览器或群聊里经常出现 VRChat 链接。现在复制以下内容后回到 VRCM，应用会先询问是否打开，再解析并进入对应页面：

- 用户：`https://vrchat.com/home/user/usr_...` 或 `usr_...`
- 世界：`https://vrchat.com/home/world/wrld_...` 或 `wrld_...`
- 群组：`https://vrchat.com/home/group/grp_...` 或 `grp_...`
- 模型：`https://vrchat.com/home/avatar/avtr_...` 或 `avtr_...`

只接受 `https://vrchat.com` / `https://www.vrchat.com` 的精确官方页面格式，并且一定先显示确认提示，不会因为剪贴板内容而静默跳转。Android 还可以在系统“打开方式”中直接把这些官网链接交给 VRCM。

一个典型流程是：在聊天中复制世界链接 → 回到 VRCM 并确认 → 查看世界与当前房间 → 邀请自己加入。用户、群组和模型链接同样无需手动搜索。

## 4. 手机相册与 VRChat+ Gallery 双向互通

移动端 Gallery 不再只是查看游戏截图，而是一条连接手机相册和 VRChat 的双向照片流程。

### 从手机相册上传到 VRChat

- 在 Gallery 的图片、图标、表情和 Print 分类中使用统一上传入口；
- Android/iOS 可直接调用系统图片选择器，Desktop 使用本地文件选择器；
- 普通 Gallery 图片支持 JPEG、PNG、GIF 和 WebP；
- Print 上传支持 JPEG、PNG、HEIC/HEIF，并会先进入裁剪与预览页面，避免上传后才发现构图不合适；
- 上传完成后自动刷新当前分类，便于确认结果。

上传内容会由设备直接发送给 VRChat，不经过 VRCM 自建服务器。Gallery 上传入口需要当前 VRChat 账户具备 VRC+ 权限。

### 把游戏照片保存到手机并快速分享

在 Gallery 中打开游戏内拍摄的照片，点击保存即可写入 Android/iOS 系统相册；Desktop 会保存到用户图片目录下的 `VRCM` 文件夹。保存到手机后，可直接使用系统相册、聊天软件或社交应用的分享能力发送给朋友。

### 在预览页直接分享原图

`16b7efa` 为图片预览增加了独立的分享操作。打开 Gallery 或 Print 图片后，点击分享按钮即可调用 Android/iOS 系统分享面板，把原图交给聊天、社交或文件应用；这个操作不会额外写入系统相册。保存按钮仍然单独负责写入 Android/iOS 相册或 Desktop 的 `Pictures/VRCM` 目录。

- 预览继续使用受控尺寸，分享和保存使用原始文件端点，避免把压缩预览当成导出文件；
- Android 通过应用私有缓存和临时授权 URI 交给系统分享，不需要把临时文件暴露给其他应用；
- iOS 直接使用系统 `UIActivityViewController`；Desktop 当前不提供图片系统分享面板，仍可保存到图片目录；
- 分享或保存失败时会显示明确错误提示，不会伪装成已完成。

VRCM 还支持缩放预览、显示各分类文件数量、长按多选和批量删除。非 VRC+ 用户也可以查看 Print，但不能使用 Gallery 上传入口。

## 5. Android 系统提醒与后台社交感知

Android 版新增独立通知设置和可选后台监测。即使暂时离开 VRCM，也可以及时知道值得关注的变化。

- 分别控制好友上线与下线提醒；
- 用好友收藏分组建立“排除选中的”或“只提醒选中的”规则；
- 对单个收藏好友设置“跟随分组 / 始终提醒 / 永不提醒”；
- 接收每次 Boop、好友请求和群组公告、活动或管理消息；
- 在 VRChat 报告服务异常与恢复正常时提醒；
- 从设置页直接检查通知权限，并进入应用管理或系统耗电设置。

<div align="center">
  <img src="../../image/Feature-Android-Notifications.png" width="360" alt="Android 通知与后台监测设置实机图"/>
</div>

后台监测默认需要用户主动开启。Android 13 及以上还需要通知权限；部分厂商系统可能限制后台运行，需要在耗电管理中允许 VRCM。iOS 和 Desktop 不提供这套 Android 前台服务与系统提醒。

应用内通知也从首页弹层迁移为独立通知中心，并恢复实时接收与处理。系统通知显示实际接收时间，好友请求和动态通知会尽量使用正确的显示名与头像。

## 6. 把手机变成线下聚会身份铭牌

长按首页自己的头像，即可打开身份铭牌。它针对 VRChat 线下聚会中“举起手机让别人认出我、交换主页与社交链接”的场景设计。

- **三种模板**：资料栏、聚光、侧签；
- **两个方向**：竖屏与横屏分别保存布局和照片裁剪；
- **多种照片来源**：VRChat 资料背景、手机相册或 VRChat Gallery；
- **可选资料**：头像、人称代词、语言、状态、状态描述、自定义短句与主选群组；
- **VRChat 视觉元素**：头像框、资料特效和铭牌特效；
- **二维码**：VRChat 个人主页和资料中的社交链接可同时展示，最多 4 个，并附短标识便于区分；
- **现场展示**：全屏显示时保持屏幕常亮，支持快速切换方向；完成后也可保存到系统图库。

<div align="center">
  <img src="../../image/Feature-Meetup-Card.png" width="360" alt="线下聚会身份铭牌实机图"/>
</div>

二维码使用通用的 VRChat 官网个人主页或用户自行配置的资料链接，不依赖另一台设备安装 VRCM。首次使用需要完成一次配置；以后长按头像会直接进入展示页。

## 7. 其他值得关注的更新

以下能力不是本次定位中的主角，但从 `1.0.7` 起也已经完成：

- 用户资料重新布局，可查看创建的世界、创建的模型、收藏世界、共同群组与最近访问世界；
- 新增模型详情页，可切换/复制可用模型，并编辑自己上传模型的名称、简介和封面；
- 群组详情加入帖子、成员、相册、群组房间与群组搜索；
- 世界详情、用户资料、群组和好友列表增加本地缓存与后台增量刷新；
- Android 发布构建启用代码与资源压缩，并清理未使用依赖，减小安装包体积；
- 导航迁移到 Navigation 3，按窗口宽度提供自适应布局和宽屏双栏显示，同时完善状态恢复、共享元素动画与 Desktop 窗口体验；
- 账户凭据改用平台安全存储，资料与活动缓存迁移到 Room；
- 改进限流重试、WebSocket 重连、切换账户隔离和前后台恢复稳定性。

## 从 1.0.7 升级

- 当前应用版本为 `1.1.1`（version code 6）。
- 原有账户、收藏与设置会继续使用；缓存结构会在首次启动时迁移或重新构建。
- 身份铭牌配置格式已升级。过早开发版本留下的不兼容配置可能需要重新设置一次；正式 `1.0.7` 用户此前没有该功能，不受影响。
- Android 若要使用系统提醒，请允许通知权限；若要在退到后台后继续统计与提醒，还需在“设置 → 通知设置”中主动开启后台监测。
