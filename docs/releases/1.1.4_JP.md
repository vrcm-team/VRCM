# VRCM 1.1.4：新機能の詳細

**Languages / 语言 / 日本語:** [English](1.1.4.md) / [中文](1.1.4_ZH.md) / [日本語](1.1.4_JP.md)

VRCM 1.1.4 では、インターフェースを刷新し、VRChat のコンテンツ管理機能を大きく拡張しました。フレンド、通知、ワールド、アバター、プロフィール、インベントリを、スマートフォンとデスクトップで同じ流れで扱えます。

## 迷わず使えるナビゲーション

ホーム、フレンド、Favorites、検索、通知、プロフィール、グループ、ワールド、アバターの各画面を、情報を確認しやすい共通レイアウトに揃えました。狭いウィンドウでは下部ナビゲーション、広いウィンドウではサイドナビゲーションを使います。リスト、シート、詳細画面ではスクロール中も必要な文脈を確認できます。

大きな文字、キーボードとマウス、プル・トゥ・リフレッシュ、長い名前にも対応しやすくなりました。アプリアイコンと起動画面も更新しています。

## フレンド、アクティビティ、招待

フレンド画面では専用ディレクトリとアクティビティのタイムラインを確認できます。通知センターからフレンドや招待に関する一般的な操作を直接実行でき、設定では再利用できる招待メッセージ枠を管理できます。画像招待では画像と場所を一緒に送り、使用したメッセージ枠と応答結果を会話内で確認できます。

グループ通知とオンライン状態には、所属するフレンドまたはグループが表示されます。アカウントを切り替えたり更新後に画面へ戻ったりしても、現在のアカウントの情報が表示され、以前の結果が混ざりません。

## ワールドとアバターを管理

ワールド詳細では、メタデータ、プレビュー画像とカバー、公開状態、Home World、保存データ、インスタンスの作成と終了をまとめて操作できます。VRChat が提供する場合は、対応プラットフォームとパッケージサイズも表示します。

アバター詳細には、Gallery の閲覧とアップロード、タグとスタイルの管理、Impostor の作成と削除、Fallback の選択、管理機能を追加しました。リクエスト中も必要な編集操作を維持し、変更できない場合は理由を表示します。

## プロフィール、インベントリ、安全設定

他のユーザーのプロフィールから、ブロック、チャットボックスやボイスのミュート、コンテンツの通報、Boop のプライバシー設定を行えます。インベントリでは絞り込み、VRChat Credits の確認、報酬コード入力を利用できます。iOS の App Store 版では、配布経路に合わない機能を表示しません。
