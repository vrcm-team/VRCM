# VRCM 1.1.3：新功能详解

**Languages / 语言 / 日本語:** [English](1.1.3.md) / [中文](1.1.3_ZH.md) / [日本語](1.1.3_JP.md)

VRCM 1.1.3 适配了 VRChat 最新的用户资料返回方式。即使 VRChat 将部分资料字段移到了新的公开资料接口，简介、名称、头像和代称等信息仍能在相应页面中正常显示。

## 1. 查看更完整的个人资料

当 VRChat 将账号基础信息和公开资料分开返回时，你自己的资料页现在仍能保持完整。像往常一样打开个人资料，即可查看可用的简介、显示名称、头像、代称和其他相关信息。

- 加载新资料时会保留已经显示的内容。
- 当旧版或新版图片字段其中一个缺失时，仍会尽量使用可用头像。
- 如果公开资料请求暂时失败，VRCM 会保留已有信息，不会把页面清空。

最终显示内容取决于 VRChat 对该账号公开了哪些资料。VRChat 未返回的私密字段不会被 VRCM 展示。

## 2. 浏览好友资料时不再缺少关键信息

好友列表、好友动态和用户资料页现在能够处理 VRChat 更新后的资料格式。打开好友资料或在好友页面之间切换时，VRCM 会组合用户信息和公开资料，让页面尽量显示完整。

- VRChat 提供时，简介、显示名称、头像和代称会继续显示。
- 缺少新版字段的旧返回内容仍然可以正常使用。
- 刷新时不会用空值覆盖之前已经加载的资料。

如果某位好友公开的信息较少，仍可能只显示有限内容，这取决于对方账号和 VRChat 的隐私设置。

## 3. 升级与平台说明

这是一次面向 Android、iOS 和 Desktop 的资料兼容性更新，不需要新增权限，账号、收藏和设置也会保持不变。

| 资料体验 | Android | iOS | Desktop |
| --- | :---: | :---: | :---: |
| 个人资料信息 | 支持 | 支持 | 支持 |
| 好友资料信息 | 支持 | 支持 | 支持 |
| 缺少字段时使用备用头像 | 支持 | 支持 | 支持 |

VRCM 1.1.3 以 GitHub 预览版形式提供，并非应用商店版本。平台提供安装包时，请选择文件名中包含 `1.1.3` 的版本。
