# VRCM 1.1.2：新機能の詳細

**Languages / 语言 / 日本語:** [English](1.1.2.md) / [中文](1.1.2_ZH.md) / [日本語](1.1.2_JP.md)

VRCM 1.1.2 では、日常的に使う操作を中心に改善しました。ワールドとアバターのお気に入り管理、すべての Gallery カテゴリーでのアップロード前編集、Android の更新ダウンロード、接続が切れた後の復旧が、よりスムーズになっています。

## 1. ワールドとアバターのお気に入りを管理する

操作前に、現在のアカウントのお気に入り状態を確認できるようになりました。ワールドまたはアバターの詳細画面を開くと、新規追加できるのか、登録済みのお気に入りを編集できるのかがボタンに表示されます。

- 既存の VRChat お気に入りグループへの追加、移動、削除ができます。
- お気に入り状態の読み込みに失敗した場合は、その場で再試行できます。
- お気に入り一覧の非表示ワールドや非表示アバターをタップして削除できます。
- ワールドとアバターのお気に入り一覧では、前回表示した内容を先に確認しながら最新情報を取得できます。
- アカウントを切り替えた後に、前のアカウントのお気に入りが表示されることはありません。

非表示コンテンツは詳細情報や現在のグループを取得できない場合があるため、削除だけが可能です。VRChat のお気に入り上限とアカウント権限は引き続き適用されます。

プロフィール画面では、作成ワールドの説明を前回の表示から引き継ぎ、変更されたワールドを必要に応じて更新します。再表示が速くなり、プロフィール情報の更新中に新しいオンライン状態が古い内容へ戻る問題も防ぎます。

## 2. Gallery 画像をアップロード前に仕上げる

対応するすべての Gallery カテゴリーで、アップロード前に編集画面を利用できるようになりました。自分のプロフィールから Gallery を開き、Gallery、Icon、Emoji、Sticker、Print のいずれかを選んで画像を追加すると、完成時の構図を確認できます。

- 画像の移動、ズーム、回転、左右・上下反転ができます。
- 画像全体を表示するか、対象の枠いっぱいに配置するかを選べます。
- Gallery、Icon、Emoji、Sticker では透明部分を維持できます。
- Print の枠に空きがある場合は、余白を白で埋められます。
- ダウンロード済み Print の外枠を検出した場合、トリミングのオン・オフを切り替えてすぐに結果を確認できます。
- 選択したカテゴリーに合った横長、正方形、または Print の比率で出力します。

アップロードが成功すると、現在のカテゴリーが更新され、新しい項目をすぐ確認できます。通信、権限、形式、画像サイズに問題がある場合も、成功したように見せず、原因に合ったエラーを表示します。

Gallery へのアップロードには VRC+ が必要です。JPEG と PNG に対応し、HEIC／HEIF は OS が対応している場合に利用できます。アニメーション画像は直接アップロードされず、編集結果は静止 PNG になります。元ファイルは 50 MiB 以下かつ 1 億画素以下である必要があり、端末上の元画像は変更されません。

## 3. 更新をより確実にダウンロードする

Android では、更新ダイアログからシステムのインストール画面まで進めるようになりました。VRCM が Android 用 APK を選び、進捗を表示し、GitHub へ直接接続できない場合は別のダウンロード経路も試します。

インストール画面を開く前に、APK が同じアプリ用であり、インストール済みアプリと同じ署名であることを確認します。Android から VRCM にアプリのインストール許可を求められる場合があります。ダウンロードを完了できない場合は、代わりに GitHub Release ページを開きます。

アプリ内ダウンロードは Android のみの機能です。iOS と Desktop では引き続きリリースページを開きます。各プラットフォームの 1.1.2 ダウンロードファイルは、バージョン番号とファイル名を統一しています。

Windows では、公開されている場合に EXE セットアップを選択でき、インストーラーは英語、簡体字中国語、繁体字中国語、日本語に対応します。MSI も選択肢として残ります。EXE はコード署名されていないため、Windows SmartScreen が不明な発行元として警告する場合があります。macOS パッケージには VRCM のアプリアイコンが表示されます。

## 4. クリップボードのリンク検出を設定する

クリップボードの読み取りは、**その他の設定**からオン・オフを選べるようになりました。初期状態ではオンになっており、ログイン中に対応する VRChat のユーザー、ワールド、グループ、アバターの URL または ID を見つけると、VRCM で開くか確認します。

通常のテキストは無視され、確認なしで画面を移動することもありません。VRCM から共有またはコピーした直後のリンクも、アプリへ戻った際に再び確認されなくなりました。設定をオフにしても、手動検索や他のアプリから直接開いたリンクには影響しません。

## 5. 接続を復旧し、最新情報を保つ

VRChat から期限切れのライブ接続を拒否された場合、保存済みのログインが有効であれば、VRCM が接続の更新と再接続を試みます。一時的な通信障害やサービス障害だけで、現在のアカウントから自動的にログアウトすることはありません。

日常的な表示も改善されています。

- お気に入りフレンドは、ゲーム内、Web、オフラインの順で見つけやすく並びます。
- プロフィールの他の情報を更新している間も、最新のオンライン状態を維持します。
- Android のアバター付きオンライン・オフライン通知に到着時刻を表示します。
- ルームカードの展開と折りたたみがより滑らかになりました。
- iOS でバックグラウンドから戻った後も、システムのダーク表示を維持します。
- フレンド位置画面の日本語表記を、より自然で正確な内容に修正しました。

この復旧機能は VRChat の認証を回避するものではありません。認証情報が拒否された場合や再確認が必要な場合は、通常のログイン画面へ戻ります。

## 6. プラットフォーム差異とアップグレード

共有されるコンテンツ機能は各対応プラットフォームで利用でき、主な違いは更新のインストール方法です。

| 機能 | Android | iOS | Desktop |
| --- | :---: | :---: | :---: |
| ワールド・アバターのお気に入り管理 | 対応 | 対応 | 対応 |
| Gallery の編集とアップロード | 対応、VRC+ が必要 | 対応、VRC+ が必要 | 対応、VRC+ が必要 |
| クリップボードのリンク検出 | 対応 | 対応 | 対応 |
| ライブ接続の復旧 | 対応 | 対応 | 対応 |
| 更新操作 | ダウンロード後にインストーラーを開く | リリースページを開く | リリースページを開く |

VRCM 1.1.2 はストア版ではなく、GitHub のプレビュー版として配布されます。既存のアカウント、お気に入り、設定は保持されます。アップグレード後にお気に入りまたはプロフィールを初めて開く際は、保存済み内容の更新に少し時間がかかる場合があります。

iOS IPA は直接テスト用の ad-hoc パッケージで、App Store 版ではありません。Windows では、前述の未署名 EXE に関する警告が表示される可能性があります。どのプラットフォームでも、ファイル名に `1.1.2` を含むダウンロードを選んでください。

[日本語 README](../../README_JP.md) に戻るか、[VRCM 1.1.2 をダウンロード](https://github.com/vrcm-team/VRCM/releases/tag/1.1.2)してください。
