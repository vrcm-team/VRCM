# VRCM 1.1.4: What's New

**Languages / 语言 / 日本語:** [English](1.1.4.md) / [中文](1.1.4_ZH.md) / [日本語](1.1.4_JP.md)

VRCM 1.1.4 brings the redesigned interface and a much broader set of VRChat management tools to the current GitHub release. Friends, notifications, worlds, avatars, profiles, and Inventory now fit into one clearer workflow on phones and desktop windows.

## A clearer way to move around

The Home, Friends, Favorites, Search, Notifications, profile, group, world, and avatar pages now share the same information-first layout. Use the bottom navigation on a narrow window or the side navigation on a wide window. Lists, sheets, and detail pages keep more of the relevant context visible while you scroll.

The interface also behaves better with large text, keyboard and mouse input, pull-to-refresh, and long names. The updated app icon and launch screen are included in this release.

## Friends, activity, and invitations

Open Friends to browse a dedicated friend directory and activity timeline. The notification center can respond to common friend and invite actions, and Settings provides reusable invite message slots. Photo invites can include an image and a location, with the selected message slot and response shown in the relevant conversation.

Group notifications and online status are shown with the friend or group they belong to. If you change accounts or return to a page after a refresh, the page keeps the current account's data instead of showing an older result.

## Manage your worlds and avatars

World details now bring common creator tasks together: edit metadata, preview and cover images, publication status, Home World, saved world data, and instance creation or closing. Platform support and package size remain visible when VRChat provides them.

Avatar details add Gallery browsing and upload, tags and style management, Impostor creation or deletion, fallback selection, and moderation controls. The page keeps editing actions available while a request is still being processed and reports a clear reason when a change cannot be completed.

## Profiles, Inventory, and safety controls

A player profile can now block a player, mute their chatbox or voice, report content, and change Boop privacy. Inventory includes filtering, VRChat Credits, and the reward-code entry point. iOS keeps store-only features out of the App Store build where required.

## Download and platform notes

| Platform | Package in this release | Update behavior |
| --- | --- | --- |
| Android | `VRCM-v1.1.4.apk` | GitHub build downloads the APK in the app and opens the system installer. |
| macOS | `VRCM-v1.1.4.dmg` | Install the desktop package from GitHub Releases. |
| iOS | `VRCM-v1.1.4.ipa` | GitHub build checks GitHub Releases; App Store builds continue to use App Store updates. |
| Windows | Not included in this macOS build | Use a Windows package when it is published separately. |

The GitHub packages are outside the App Store and Google Play review channels. Android installation may require allowing the system installer for the package source, and the iOS IPA is ad-hoc signed for direct distribution.
