# VRCM 1.1.3: What's New

**Languages / 语言 / 日本語:** [English](1.1.3.md) / [中文](1.1.3_ZH.md) / [日本語](1.1.3_JP.md)

VRCM 1.1.3 keeps user profiles reliable after VRChat moved several profile fields to a newer public-profile response. Bios, names, avatars, and pronouns can continue to appear in the places where you use them.

## 1. View complete personal profiles

Your own profile now remains readable even when VRChat sends basic account data and public profile data separately. Open your profile as usual to see the available bio, display name, avatar, pronouns, and related information together.

- Existing profile information is retained while newer details are loaded.
- An avatar can still be shown when one of the older or newer image fields is absent.
- If the public-profile request is temporarily unavailable, VRCM keeps the information it already has instead of clearing the page.

The result depends on what VRChat makes visible for the account. VRCM does not expose private fields that are not returned by VRChat.

## 2. Browse friend profiles without missing fields

Friend lists, friend activity, and user profile pages now handle the newer VRChat profile format. Open a friend’s profile or move between friend views as before; the page can combine the user record with the public profile details needed for a complete presentation.

- Bios, display names, avatars, and pronouns continue to appear when supplied by VRChat.
- Older responses that omit a newer field remain usable.
- Previously loaded information is not replaced by an empty value during a refresh.

Some friends may still have fewer details because their account or VRChat privacy settings do not provide them.

## 3. Upgrade and platform notes

This release is a compatibility update for the shared profile experience on Android, iOS, and Desktop. No new permission is required, and your account, favorites, and settings remain unchanged.

| Profile experience | Android | iOS | Desktop |
| --- | :---: | :---: | :---: |
| Personal profile information | Yes | Yes | Yes |
| Friend profile information | Yes | Yes | Yes |
| Avatar fallback when a field is missing | Yes | Yes | Yes |

VRCM 1.1.3 is distributed as a GitHub preview release, not a store release. Choose a package whose name contains version `1.1.3` when one is provided for your platform.
