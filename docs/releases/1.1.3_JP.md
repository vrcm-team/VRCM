# VRCM 1.1.3：新機能の詳細

**Languages / 语言 / 日本語:** [English](1.1.3.md) / [中文](1.1.3_ZH.md) / [日本語](1.1.3_JP.md)

VRCM 1.1.3 は、VRChat の新しいユーザープロフィール形式に対応しました。VRChat が一部のプロフィール項目を公開プロフィール用の応答へ移した後も、自己紹介、表示名、アバター、代名詞などを必要な画面で確認できます。

## 1. 自分のプロフィールをより完全に表示

VRChat がアカウントの基本情報と公開プロフィールを別々に返す場合でも、自分のプロフィールを表示しやすくなりました。いつもどおりプロフィールを開くと、利用可能な自己紹介、表示名、アバター、代名詞などがまとめて表示されます。

- 新しい情報を読み込む間も、すでに表示されているプロフィール内容を保持します。
- 以前の画像項目または新しい画像項目のどちらかがない場合も、利用できるアバターを使って表示します。
- 公開プロフィールの取得が一時的に失敗しても、既存の情報を消去しません。

表示できる内容は、VRChat がそのアカウントに公開している情報に依存します。VRChat から返されない非公開項目を VRCM が表示することはありません。

## 2. フレンドのプロフィールでも項目が欠けにくく

フレンド一覧、フレンドアクティビティ、ユーザープロフィール画面が、新しい VRChat のプロフィール形式に対応しました。フレンドのプロフィールを開いたり画面を切り替えたりすると、ユーザー情報と公開プロフィールを組み合わせて、必要な内容をできるだけ完全に表示します。

- VRChat から提供される場合、自己紹介、表示名、アバター、代名詞が表示されます。
- 新しい項目がない古い応答でも、表示できる情報はそのまま利用できます。
- 更新時に空の値で、すでに読み込んだプロフィールを上書きしません。

フレンドのアカウントや VRChat のプライバシー設定によっては、表示できる情報が少ない場合があります。

## 3. アップデートとプラットフォームについて

Android、iOS、Desktop 共通のプロフィール互換性を改善したアップデートです。新しい権限は必要なく、アカウント、フレンド登録、設定もそのまま保持されます。

| プロフィール機能 | Android | iOS | Desktop |
| --- | :---: | :---: | :---: |
| 自分のプロフィール情報 | 対応 | 対応 | 対応 |
| フレンドのプロフィール情報 | 対応 | 対応 | 対応 |
| 項目がない場合のアバター補完 | 対応 | 対応 | 対応 |

VRCM 1.1.3 は GitHub のプレビューリリースとして提供され、アプリストア版ではありません。お使いのプラットフォーム向けパッケージが提供されている場合は、ファイル名に `1.1.3` が含まれるものを選択してください。
