# VRCM 1.1.6：新機能の詳細

**Languages / 语言 / 日本語:** [English](1.1.6.md) / [中文](1.1.6_ZH.md) / [日本語](1.1.6_JP.md)

VRCM 1.1.6 では、QR コード機能、統計データの移行、アカウント切り替えに対応した分類別の設定画面を追加しました。セッションの復旧、プロフィール編集、グループ操作、Android のアプリ内更新も改善しています。

## VRChat のコードを読み取り、プロフィールを共有

Android と iOS では、スキャナーからカメラや写真ライブラリの画像を使って、対応する VRChat リンクを読み取れます。画像に複数のコードがある場合は対象を選択できます。Android では、ホーム画面のアプリアイコンからスキャナーを開くショートカットも利用できます。

VRChat のデバイスログイン用コードでは、現在のアカウントへのアクセスを承認する前に、リクエスト時刻と取得できた地域情報を確認できます。期限切れやアカウント変更後は再確認が必要です。自分がログインしようとしているデバイスのリクエストだけを承認してください。

独立した「自分の QR コード」画面では、プロフィールのコードを表示し、スタイルを切り替えたりカードを共有したりできます。Desktop はカメラによるスキャンに対応していません。

## 統計データを別の環境へ移行

設定 → プライバシーとデータから、統計をインポート・エクスポートできます。SQLite ファイルとしてバックアップし、対応する VRCM または VRCX のデータベースを読み込めます。インポート前にユーザー、アクティビティ、遭遇の件数を確認でき、重複する記録は統合されます。

VRCM のバックアップは現在のアカウントと照合されます。VRCX のゲームログには複数アカウントのデータが含まれる場合があり、インポートした記録は現在ログイン中のアカウントに割り当てられます。アカウントを切り替えると処理は中断します。Android では、大きなスナップショットやシステムのファイル選択画面から読み込む場合の信頼性も改善しました。

## 設定の分類とアカウント切り替え

設定を、アカウントの安全性、外観、通知、プライバシーとデータ、アプリ情報の各画面に分類しました。通知項目はプラットフォームの対応状況に応じて表示します。保存済みアカウントへの切り替えとログアウトは、アカウントとセキュリティの画面にまとめています。

バックグラウンドでセッションが失効した場合、認証を復旧して更新を再開します。復旧結果は現在のアカウントに紐付けられ、遅れて届いた応答が新しいセッションを上書きしないようにしています。一括削除は一覧の読み込み完了後すぐに開始でき、認証更新後も残りの処理を継続します。ミュートの切り替え成功後に届いたセッション通知が操作結果を上書きする問題も修正しました。

## 見やすいアクティビティと安定した操作

フレンドの表示名変更とアバター変更をアクティビティに表示し、アバター専用の絞り込みを追加しました。展開したルームカードからオーナーのプロフィールを開けます。グループのルームでは自分への招待が可能になり、ワールド詳細には遷移元のルームを読み込みます。

プロフィール編集を VRChat の新しいプロフィール API に対応させ、保存結果を同期します。グループ代表の状態を各プロフィール画面で一致させ、アバター一覧の対応プラットフォーム表示を修正しました。Windows では背景ぼかしによるフリーズも修正しています。

## Android の更新と配布について

GitHub の Android 版は、ダウンロードした APK のパッケージ名と署名がインストール済みアプリと一致するか確認します。不一致の場合は別のミラーを試さず更新を停止します。無効なファイルや通信の中断では、別の配信元から再試行できます。

Android と iOS のビルド番号は 11 になります。ダウンロードできるパッケージは Release の添付ファイルを確認してください。GitHub の Android 版はシステムインストーラーを使用し、Google Play 版と App Store 版は各ストアで更新します。iOS IPA はサイドロード用です。
