# VRCM 1.1.2：新功能详解

**Languages / 语言 / 日本語:** [English](1.1.2.md) / [中文](1.1.2_ZH.md) / [日本語](1.1.2_JP.md)

VRCM 1.1.2 重点改善日常使用流程：世界与模型收藏更容易管理，Gallery 各分类都能在上传前编辑，Android 更新下载更顺畅，临时连接问题也不再轻易打断当前账号。

## 1. 管理收藏世界与收藏模型

执行操作前，现在可以先确认当前账号的收藏状态。打开世界或模型详情页，按钮会明确显示可以新增收藏，还是编辑已有收藏。

- 可在现有 VRChat 收藏分组中添加、移动或移除世界与模型；
- 收藏状态加载失败时，可以直接重试；
- 在收藏列表中点击已隐藏的世界或模型，可以移除这条已不可用的收藏；
- 打开收藏世界与模型列表时，会先显示此前看过的内容，再检查最新变化；
- 切换账号后，不会显示上一个账号的收藏。

隐藏内容可能已无法提供详情和当前分组信息，因此只支持移除，不能打开详情或移动分组。收藏数量上限和账号权限仍以 VRChat 的规则为准。

资料页也会保留此前加载过的创建世界说明，仅在需要时更新发生变化的世界。再次打开时能更快看到完整内容，刷新其他资料时也不会把最新在线状态变回旧状态。

## 2. 在上传前完成 Gallery 图片编辑

Gallery 所有受支持的分类现在都会先进入编辑器。通过自己的资料页打开 Gallery，选择相册、图标、表情、贴纸或 Print，再选择图片，即可预览最终构图。

- 上传前可移动、缩放、旋转以及水平或垂直翻转图片；
- 可选择完整显示图片，或让图片填满目标区域；
- 相册、图标、表情和贴纸会保留透明区域；
- Print 图片未铺满画面时，可用白色填充空白区域；
- 识别到曾经下载的 Print 时，可实时开关外框裁剪并查看结果；
- 根据所选分类使用正确的横向、方形或 Print 输出比例。

上传成功后，当前分类会立即刷新，方便确认新内容。遇到网络、权限、格式或图片尺寸问题时，会明确显示失败原因，不再出现实际失败却像是成功的情况。

上传 Gallery 内容需要 VRC+。编辑器支持 JPEG、PNG，以及系统能够读取时的 HEIC／HEIF；不支持直接上传动画文件，编辑结果会保存为静态 PNG。原文件不能超过 50 MiB 或 1 亿像素，设备上的原图不会被修改。

## 3. 减少更新下载的阻碍

Android 用户现在可以从更新弹窗直接进入系统安装界面。VRCM 会选择对应的 APK、显示下载进度，并在 GitHub 无法直连时尝试其他下载线路。

打开安装界面前，VRCM 会确认 APK 属于同一个应用，并与当前安装版本使用相同签名。Android 仍可能要求授予 VRCM 安装应用的权限；如果下载无法完成，则会改为打开 GitHub Release 页面。

应用内下载仅支持 Android。iOS 与 Desktop 仍会打开 Release 页面，各平台的 1.1.2 下载文件使用一致的版本号和命名。

Windows 用户可以在提供时选择 EXE 安装程序，安装界面支持英文、简体中文、繁体中文和日文，同时保留 MSI 作为另一种选择。EXE 尚未进行代码签名，因此 Windows SmartScreen 可能显示“未知发布者”警告。macOS 安装包现在会显示 VRCM 应用图标。

## 4. 自主管理剪贴板链接识别

剪贴板读取现在可以在**更多设置**中开启或关闭。该选项默认开启；登录后发现受支持的 VRChat 用户、世界、群组或模型链接及 ID 时，VRCM 会先询问是否打开。

普通剪贴板文本会被忽略，VRCM 也不会在未经确认时跳转。通过 VRCM 刚刚分享或复制的链接，在返回应用后不会再次触发提示。关闭该选项不影响手动搜索，也不影响从其他应用直接打开链接。

## 5. 恢复连接并保持信息准确

当 VRChat 拒绝已经过期的实时连接时，只要保存的登录信息仍然有效，VRCM 就会尝试续期并重新连接。临时网络或服务故障不会再直接导致当前账号退出登录。

其他日常体验也得到改善：

- 好友收藏列表会依次显示游戏内、网页在线和离线好友，更容易找到正在游玩的好友；
- 资料页刷新其他信息时，会保留最新在线状态；
- Android 带头像的上线、下线通知会显示实际到达时间；
- 房间卡片展开和收起时更加流畅；
- iOS 从后台返回后会继续使用系统深色外观；
- 好友位置页的日文文案更加自然、准确。

连接恢复不会绕过 VRChat 认证。如果账号凭据被拒绝，或需要重新验证，VRCM 仍会回到正常登录流程。

## 6. 平台差异与升级提示

共享内容功能在各支持平台上保持一致，主要区别在于更新的安装方式。

| 功能 | Android | iOS | Desktop |
| --- | :---: | :---: | :---: |
| 世界与模型收藏管理 | 支持 | 支持 | 支持 |
| Gallery 编辑与上传 | 支持，需要 VRC+ | 支持，需要 VRC+ | 支持，需要 VRC+ |
| 剪贴板链接识别 | 支持 | 支持 | 支持 |
| 实时连接恢复 | 支持 | 支持 | 支持 |
| 更新操作 | 下载并打开安装界面 | 打开 Release 页面 | 打开 Release 页面 |

VRCM 1.1.2 通过 GitHub 以预览版形式发布，并非应用商店正式版本。升级后会保留原有账号、收藏和设置；首次进入收藏或资料页时，更新此前保存的内容可能需要一点时间。

iOS IPA 是用于直接测试的临时签名安装包，并非 App Store 版本。Windows 用户可能遇到前述未签名 EXE 警告。无论使用哪个平台，请选择文件名中包含 `1.1.2` 的下载文件。
