# VRCM 1.1.4：新功能详解

**Languages / 语言 / 日本語:** [English](1.1.4.md) / [中文](1.1.4_ZH.md) / [日本語](1.1.4_JP.md)

VRCM 1.1.4 带来了全新的界面和更完整的 VRChat 内容管理工具。好友、通知、世界、模型、资料和库存现在可以在手机与桌面窗口中使用同一套清晰的操作流程。

## 更清晰的页面导航

主页、好友、收藏、搜索、通知、资料、群组、世界和模型页面采用统一的信息式布局。窄窗口使用底部导航，宽窗口使用侧边导航；列表、弹层和详情页在滚动时会保留更多上下文。

界面对大字体、键盘鼠标操作、下拉刷新和长名称的适应也更好。本次版本同时更新了应用图标和启动画面。

## 好友、动态与邀请

打开好友页面即可浏览独立的好友目录和动态时间线。通知中心可以直接处理常见的好友与邀请操作，设置页提供可重复使用的邀请消息槽。图片邀请可以同时发送图片和位置，并在相应对话中显示使用的消息槽与响应结果。

群组提醒和在线状态会显示所属好友或群组。切换账号或刷新后返回页面时，页面会保留当前账号的数据，不会再次显示旧账号的结果。

## 管理世界与模型

世界详情页集中提供常用的创作者操作：编辑元数据、预览图和封面、发布状态、Home World、世界保存数据，以及创建或关闭实例。VRChat 提供平台支持和包体大小时，页面也会继续显示这些信息。

模型详情页增加 Gallery 浏览与上传、标签和样式管理、Impostor 创建或删除、Fallback 选择以及管理工具。请求进行中时，页面会保留必要的编辑入口；无法完成操作时会说明原因。

## 资料、库存与安全设置

打开其他玩家的资料页，可以屏蔽玩家、静音聊天框或语音、举报内容，并调整 Boop 隐私。库存页支持筛选、查看 VRChat Credits 和进入奖励码兑换。按照商店要求，iOS App Store 版本不会显示仅适用于其他渠道的功能。
