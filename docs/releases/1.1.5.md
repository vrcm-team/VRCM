# VRCM 1.1.5: What's New

**Languages / 语言 / 日本語:** [English](1.1.5.md) / [中文](1.1.5_ZH.md) / [日本語](1.1.5_JP.md)

VRCM 1.1.5 adds QR tools, statistics transfer, and categorized settings with account switching. It also improves session recovery, profile editing, group interactions, and Android updates.

## Scan VRChat codes and share your profile

On Android and iOS, open the scanner to recognize supported VRChat links with the camera or from an image in your photo library. If an image contains multiple codes, select the one you want. Android also provides a launcher shortcut to the scanner.

For a VRChat device-login code, review the request time and available location information before approving access to your current account. Expired codes and account changes require a fresh confirmation. Only approve a request from a device you are signing in to.

The separate My QR Code page displays your profile code, supports switching its appearance, and lets you share the card. Desktop does not provide camera scanning.

## Move your statistics between installations

Settings → Privacy & Data provides statistics import and export. Export a SQLite file as a backup, or import a supported VRCM or VRCX database. Before importing, review the counts of users, activities, and encounters; duplicate records are merged.

VRCM backups are checked against the current account. VRCX game logs can contain data from multiple accounts, and imported records are assigned to the account currently signed in. Switching accounts interrupts the operation. Android also handles large snapshots and files selected through document providers more reliably.

## Find settings and switch accounts

Settings now groups account security, appearance, notifications, privacy and data, and app information into separate pages. Notification options depend on platform support. Account & Security brings saved-account switching and sign-out together.

When a background session expires, VRCM attempts to restore authentication and resume updates. Recovery remains tied to the current account so a delayed result cannot replace a newer session.

## Clearer activity and more reliable interactions

Friend activity shows display-name changes and avatar changes, with a separate avatar filter. Expanded room cards can open the owner's profile. Group rooms support inviting yourself, and world details load the room through which they were opened.

Profile editing follows VRChat's updated profile API and keeps save results in sync. Group representation updates stay consistent across profile pages, avatar lists report platform support more accurately, and Windows avoids a freeze caused by progressive backdrop blur.

## Android updates and distribution

The GitHub Android build checks downloaded APKs against the installed app's package and signature. A mismatched package stops the update instead of trying additional mirrors. Invalid or interrupted downloads can still fall back to another source.

Android and iOS build numbers advance to 10. Available packages are listed on the release page. GitHub Android builds use the system installer, while Google Play and App Store builds keep their store-specific update paths. iOS IPA packages remain intended for sideloading.
