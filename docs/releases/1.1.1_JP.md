# VRCM 1.1.1 新機能の詳細

**Languages / 语言 / 言語:** [English](1.1.1.md) · [中文](1.1.1_ZH.md) · [日本語](1.1.1_JP.md)

この文書では、`1.0.7` から `1.1.1` までの主なユーザー向け変更を紹介します。今回の更新は、プロフィール閲覧ページを増やすだけのものではありません。交友関係を理解し、一緒に遊んだ時間を端末内に残し、スマートフォンで重要な動きを知り、共有リンクから次のゲームやオフライン交流へ素早く進める、よりソーシャルで便利な VRChat コンパニオンを目指しています。

デスクトップでの情報管理やログ閲覧を重視する VRCX に対して、VRCM はモバイルでのソーシャル統計、システム通知、ゲーム内交流、オフラインでの交流を重視しています。これは製品の重点の違いであり、API、データファイル、機能の互換性や代替を保証するものではありません。

本文のモバイル画面は OPPO の Android 実機で撮影しました。フレンド関係グラフは全体を匿名化し、通知画面には実際のフレンド通知本文を含めていません。

## 1. 交友関係を理解し、一緒に遊んだ時間を残す

### フレンド関係グラフ

自分のプロフィールで操作メニューを開き、**フレンド関係グラフを表示**を選ぶと、共通フレンド関係からインタラクティブなグラフを作成します。

- **コミュニティ表示**は、つながりの強いフレンドをソーシャルグループに分け、色と境界で構造を見やすくします。
- **自分中心表示**は自分の周囲の関係を強調し、共通フレンド数の多い相手を表示します。
- 拡大、移動、ノード選択、共通フレンド確認に対応します。上部の更新操作で関係データを再取得し、次回は端末内キャッシュを先に表示できます。
- グラフは端末内にキャッシュされ、次回はキャッシュを先に表示して必要なときだけ更新できます。

このグラフが示すのは、VRChat の共通フレンドデータから推定した接続構造です。現実の親密度を測定するものではありません。スクリーンショット内のアバターと表示名は判別できないよう処理しています。

### フレンドアクティビティと一緒に遊んだ統計

フレンドプロフィールでは、VRCM が端末上で観測したソーシャルデータを確認できます。

- 最後に会った日時、会った回数、一緒に遊んだ合計時間。
- 最近一緒に遊んだフレンド。
- オンライン、オフライン、ワールド移動、ステータス変更、Bio 変更。
- 同じインスタンスに入った時刻と離れた時刻のタイムライン。
- ワールド名、インスタンスの公開範囲、Bio 変更内容の差分。

これらはアカウントごとに端末内データベースへ保存され、VRCM 運営のサーバーにはアップロードされません。統計の対象は VRCM の動作中に観測できた範囲だけです。Android では任意のバックグラウンド監視を有効にすると、アプリを閉じた後も観測を続けられます。VRChat が提供する完全な履歴ではなく、VRCM インストール以前の動きを復元することもできません。

## 2. 見つけた相手やワールドから、そのまま交流へ

VRCM は、モバイルでよく使う交流操作をプロフィール、ワールド、通知の流れに組み込みました。

- フレンドのインスタンスを確認し、自分への招待を送る。
- 通常、ハート、手を振る、笑う、いいね、考える、驚く、怒るの各 Boop を送る。
- 通知センターからフレンドリクエスト、招待、Boop の返信を処理する。
- 共通フレンド、共通グループ、相手が作成したワールドやアバターを続けて見る。
- 自分のステータス、説明、Bio、代名詞、言語、ソーシャルリンクを編集する。
- ユーザー、ワールド、グループ、アバターの公式 VRChat URL をシステム共有で送る。

目的は、人物やワールドを見つけてから実際に交流するまでの操作を短くすることであり、情報ページをスマートフォンに複製するだけではありません。

## 3. リンクをコピーして VRCM で続ける

チャット、ブラウザ、グループ会話で受け取った次の内容をコピーし、VRCM に戻って確認すると、対応するページへ直接移動できます。

- ユーザー：`https://vrchat.com/home/user/usr_...` または `usr_...`
- ワールド：`https://vrchat.com/home/world/wrld_...` または `wrld_...`
- グループ：`https://vrchat.com/home/group/grp_...` または `grp_...`
- アバター：`https://vrchat.com/home/avatar/avtr_...` または `avtr_...`

対応するのは `https://vrchat.com` または `https://www.vrchat.com` の正確な公式形式だけです。クリップボードに内容があるだけで勝手に移動することはなく、必ず確認画面を表示します。Android ではシステムの**アプリで開く**から公式リンクを VRCM に直接渡すこともできます。

たとえば、チャットでワールド URL をコピーし、VRCM に戻って確認し、ワールドと現在のインスタンスを見て、自分への招待を送る、という流れを手動検索なしで行えます。

## 4. スマートフォンと VRChat+ Gallery の双方向連携

Gallery はゲーム画像を見るだけの画面ではなく、スマートフォンの写真ライブラリと VRChat を双方向につなぐ機能になりました。

### スマートフォンの写真を VRChat へアップロード

- Gallery、Icon、Emoji、Print の各分類で共通のアップロード操作を利用できます。
- Android/iOS はシステム画像選択、Desktop はローカルファイル選択を開きます。
- 通常の Gallery アップロードは JPEG、PNG、GIF、WebP に対応します。
- Print は JPEG、PNG、HEIC/HEIF に対応し、アップロード前にトリミングと構図のプレビュー画面を開きます。
- アップロード成功後は現在の分類を自動で再読み込みします。

選択した画像は端末から VRChat へ直接送信され、VRCM 運営のサーバーを経由しません。Gallery のアップロード操作には、現在の VRChat アカウントの VRC+ 権限が必要です。

### ゲーム写真をスマートフォンに保存してすぐ共有

ゲーム内で撮影され Gallery に同期された写真を開き、保存操作を使うと Android/iOS のシステム写真ライブラリに書き込まれます。Desktop ではユーザーの Pictures ディレクトリ内の `VRCM` フォルダーに保存します。スマートフォンへ保存した後は、写真アプリ、メッセージアプリ、SNS の共有機能からすぐに送れます。

### プレビューから原画像を直接共有

`16b7efa` では画像プレビューに独立した共有操作を追加しました。Gallery または Print の画像を開いて共有ボタンを押すと、Android/iOS のシステム共有シートへ原画像を渡し、チャット、SNS、ファイルアプリなどへ送れます。この操作だけでは写真ライブラリに別コピーを作りません。保存ボタンは従来どおり Android/iOS の写真ライブラリ、または Desktop の `Pictures/VRCM` への保存に使います。

- 表示にはメモリ使用量を抑えたサイズを使い、共有・保存には原画像の URL を使います。
- Android はアプリ専用キャッシュと一時 URI 権限を使って共有します。
- iOS は `UIActivityViewController` を使います。Desktop では画像のシステム共有シートは提供せず、画像フォルダーへの保存に対応します。
- 共有または保存に失敗した場合はエラーを表示します。

拡大プレビュー、分類ごとのファイル数、長押しによる複数選択、一括削除にも対応します。VRC+ でないユーザーも Print の閲覧はできますが、Gallery のアップロード操作は利用できません。

## 5. Android システム通知とバックグラウンド監視

Android 版には独立した通知設定と任意のバックグラウンド監視が加わり、VRCM を離れた後でも重要な動きを把握できます。

- フレンドのオンライン通知とオフライン通知を個別に設定。
- お気に入りグループから**選択した対象を除外**または**選択した対象だけ通知**するルールを作成。
- お気に入りフレンドごとに**グループ設定に従う / 常に通知 / 通知しない**を指定。
- Boop、フレンドリクエスト、グループのお知らせ、イベント、管理メッセージを通知。
- VRChat のサービス障害と復旧を通知。
- 通知権限の確認と、アプリ管理・バッテリー管理設定への直接移動。

<div align="center">
  <img src="../../image/Feature-Android-Notifications.png" width="360" alt="Android の通知とバックグラウンド監視設定の実機画面"/>
</div>

バックグラウンド監視はユーザーが有効にした場合だけ動作します。Android 13 以降は通知権限も必要で、端末メーカーによってはバッテリー設定で VRCM を許可する必要があります。iOS と Desktop には、この Android 前景サービスとシステム通知はありません。

アプリ内通知もホームのオーバーレイから独立した通知センターへ移動し、リアルタイム受信と操作を復元しました。システム通知には実際の受信時刻を表示し、可能な場合は正しい表示名とアバターを使用します。

## 6. スマートフォンを交流会向けネームカードに

ホームで自分のアバターを長押しすると、VRChat の交流会でスマートフォンを掲げ、本人確認やプロフィール・ソーシャルリンク交換に使えるネームカードを開きます。

- **3 つのテンプレート：** 情報バー、スポットライト、サイドタグ。
- **2 つの方向：** 縦画面と横画面でレイアウトと写真トリミングを別々に保存。
- **複数の写真ソース：** VRChat プロフィール背景、端末の写真、VRChat Gallery。
- **選択可能な情報：** アバター、代名詞、言語、ステータス、説明、短い自由文、メイングループ。
- **VRChat の視覚要素：** アバターフレーム、プロフィールエフェクト、ネームプレートエフェクト。
- **QR コード：** VRChat プロフィールとプロフィール内ソーシャルリンクを最大 4 個、短い識別ラベル付きで表示。
- **会場での表示：** 全画面でスリープを防止し、方向を素早く切り替え、完成画像を保存。

<div align="center">
  <img src="../../image/Feature-Meetup-Card.png" width="360" alt="スマートフォンに表示した交流会向けネームカードの実機画面"/>
</div>

QR コードには通常の VRChat Web プロフィールまたはユーザーがプロフィールに設定したリンクを使います。読み取る側に VRCM は不要です。初回だけ編集を完了すると、次回からはアバターの長押しで表示画面へ直接進みます。

## 7. その他の主な更新

今回の製品メッセージの中心ではありませんが、`1.0.7` 以降には次の更新も含まれます。

- 作成ワールド、作成アバター、お気に入りワールド、共通グループ、最近訪れたワールドを含むユーザープロフィール再設計。
- 利用可能なアバターの切り替え・コピーと、自作アバターの名前・説明・カバー編集に対応するアバター詳細画面。
- グループ投稿、メンバー、ギャラリー、グループインスタンス、グループ検索。
- ワールド、ユーザープロフィール、グループ、フレンドリストの端末内キャッシュと差分更新。
- Navigation 3 への移行、ワイド画面の 2 ペイン表示、状態復元、共有要素アニメーション、Desktop ウィンドウ改善。
- アカウント認証情報のプラットフォーム安全ストレージ化と、プロフィール・アクティビティキャッシュの Room 化。
- レート制限の再試行、WebSocket 再接続、アカウント切り替え分離、前景・背景復帰の安定性改善。

## 1.0.7 からのアップグレード

- 現在のアプリバージョンは `1.1.1`（version code 6）です。
- 既存のアカウント、お気に入り、設定は引き続き利用でき、キャッシュ構造は初回起動時に移行または再構築されます。
- 開発中にネームカード設定形式が変更されました。初期開発版の互換性がない設定は再設定が必要な場合があります。正式版 `1.0.7` にはこの機能がないため影響しません。
- Android のシステム通知を使うには通知権限を許可してください。バックグラウンドで統計と通知を続ける場合は、**設定 → 通知設定**でバックグラウンド監視も有効にします。
